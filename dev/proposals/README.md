# Proposals

Designs for features that have not been built. Nothing here is normative:
no proposal in this directory has been accepted, scheduled, or committed to,
and several describe tabs that ship empty today. They are kept because the
analysis behind them is real - measured against a named commit, with the
rejected alternatives written down - and redoing that analysis costs more
than storing it. Read them for the reasoning, not for what the module does.
What the module does is [`docs/`](../../docs/README.md); what is and is not
planned is [`docs/ROADMAP.md`](../../docs/ROADMAP.md).

D1-D5 are per-tab proposals; `tab-roadmap-proposal.md` is the synthesis
across them; `m40-decision-brief.md` and the two research notes support D4.
