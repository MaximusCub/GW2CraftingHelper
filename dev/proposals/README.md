# Proposals

Design write-ups. Some shipped, some did not, and the directory is a mix of
both.

SHIPPED, and load-bearing: `d1-snapshot-about-settings.md`,
`d2-log-system.md`, `d3-plan-history.md`, `d4-crafting-ranker.md` and
`addendum-astral-acclaim.md` describe behaviour the module now has. Source
comments cite them by section as the reasoning behind shipped decisions, and
CI checks those citations resolve, so these are the design-rationale tier for
their tabs rather than speculation. Read them before changing that code.

NOT BUILT: `d5-next-step-feasibility.md`, `p1-earned-sources.md`,
`module-capability-audit.md` and the four legendary research files. Nothing
in them is normative and none has been scheduled.

The analysis behind all of them is measured against a named commit, with the
rejected alternatives written down.
What the module does is [`docs/`](../../docs/README.md); what is and is not
planned is [`docs/ROADMAP.md`](../../docs/ROADMAP.md).

D1-D5 are per-tab proposals; `tab-roadmap-proposal.md` is the synthesis
across them; `m40-decision-brief.md` and the two research notes support D4.
